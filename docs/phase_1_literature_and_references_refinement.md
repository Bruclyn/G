# Phase 1: Literature Review and References Refinement

## Scope of This Phase
This phase focuses only on improving citation quality, APA 7 consistency, literature flow, comparative strength, and research gap clarity for the project titled **“Design and Implementation of a Student Management and Academic Performance Analysis System Using SQL Server and Tableau.”**

---

## 1. Citation–Reference Consistency Correction Protocol
Use the checklist below across all chapters before revising content depth:

1. **In-text citation match check**
   - Every in-text citation must appear in the reference list.
   - Every reference list entry must be cited in text at least once.

2. **Author-year alignment**
   - Ensure spelling and year in-text exactly match the reference list entry.
   - If two works by same author and year exist, use suffixes (e.g., 2020a, 2020b).

3. **APA 7 formatting rules**
   - Journal titles and volume numbers in italics.
   - Sentence case for article titles.
   - DOI presented as URL (https://doi.org/...).
   - Use “&” in parenthetical citations and in references.

4. **Direct claim traceability**
   - Each technical claim should be backed by one of:
     - empirical journal article,
     - reputable conference paper,
     - official documentation (for SQL Server/Tableau features).

---

## 2. Upgraded Literature Review Flow (Recommended Order)
Reorganize the Literature Review into the following subsections for stronger logic:

1. **Student Management Information Systems (SMIS) foundations**
2. **Academic performance analytics in higher education**
3. **Database design quality (normalization, constraints, integrity)**
4. **GPA computation approaches and automation**
5. **At-risk student detection models (rule-based vs predictive)**
6. **Business intelligence dashboards for education (Tableau-focused)**
7. **Synthesis and research gaps**

This sequence moves from broad system context to the exact analytical and implementation focus of the project.

---

## 3. Strengthened Comparative Review (Merged Meta-Analysis)
Replace multiple fragmented meta-analysis sections with one consolidated comparative section.

### 3.1 Comparative Matrix Template (Use as Main Table)
For each study, document:

- **Study context and objective**
- **Methodology** (e.g., case study, survey, system development, data mining)
- **Data scope** (institution size, semesters, variables)
- **Strengths**
- **Weaknesses/limitations**
- **Research gap identified**
- **Relevance to this project**

### 3.2 Narrative Integration Pattern
After presenting the matrix, add a narrative using this pattern:

- Paragraph A: What most studies do well.
- Paragraph B: What most studies fail to address.
- Paragraph C: Why SQL Server + Tableau + rule-based GPA/risk workflows are still needed.

This format removes duplication while preserving analytical depth.

---

## 4. Claim-to-Evidence Upgrades (What to Replace)
Improve weak statements such as:

- “Many institutions use dashboards.”
- “Databases improve performance.”
- “Risk detection helps students.”

Convert them into verifiable, supported claims:

- “Prior studies report improved monitoring accuracy when centralized student records are integrated with BI dashboards (Author, Year).”
- “Normalized schemas and enforced foreign keys reduce data inconsistency in academic record systems (Author, Year).”
- “Early-warning indicators based on GPA/attendance thresholds support earlier intervention for at-risk students (Author, Year).”

---

## 5. Research Gap Clarification (Final Gap Statement Template)
Use a concise, defendable gap statement:

> Existing studies often examine student records systems, GPA analytics, or dashboards in isolation. Fewer undergraduate-focused implementations provide an integrated, relational SQL Server backend with automated GPA and risk procedures plus Tableau dashboards for operational decision-making. This project addresses that integration gap through a practical end-to-end design suitable for departmental deployment.

---

## 6. APA 7 Consistency Rules to Enforce Across the Document

- Use consistent citation style: (Surname, Year).
- For 3+ authors, use first author + *et al.* in-text.
- List up to 20 authors in the reference list (APA 7 rule).
- Use hanging indent in references.
- Ensure capitalization consistency in titles (sentence case).
- Use retrieval dates only when content is designed to change over time.
